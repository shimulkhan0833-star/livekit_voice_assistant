Yes, if you **self-host LiveKit**, you do **not need LiveKit Cloud API keys**. However, you still need **LiveKit credentials** (API key and secret) generated by your own LiveKit server.

The distinction is important.

---

## LiveKit Cloud

If you use LiveKit's managed service:

```text
Your App
   |
   |
LiveKit Cloud
   |
   |
Users
```

You get:

```env
LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=xxxxx
LIVEKIT_API_SECRET=xxxxx
```

These credentials come from LiveKit Cloud dashboard.

---

## Self-hosted LiveKit

You run:

```text
Your Server
     |
     |
LiveKit Server
     |
     |
Your Voice Agent
```

You configure your own:

```yaml
# livekit.yaml

keys:
  my_voice_agent_key: my_secret_value
```

Then your app uses:

```env
LIVEKIT_URL=wss://your-domain.com
LIVEKIT_API_KEY=my_voice_agent_key
LIVEKIT_API_SECRET=my_secret_value
```

These are **your own keys**, not LiveKit Cloud keys.

---

## Why are keys still needed?

Because LiveKit needs to authenticate:

- who can create rooms
- who can join rooms
- who is an agent
- who is a participant

Example:

Your backend creates a token:

```python
token = AccessToken(
    api_key,
    api_secret
)

token.with_identity(
    "customer_123"
)

token.with_grants(
    room_join=True
)
```

Then the user joins:

```text
Browser
   |
   |
Token
   |
   |
LiveKit Server
```

LiveKit checks:

"Is this user allowed to join this room?"

```text
                 User
                  |
                  |
          LiveKit Client SDK
                  |
                  |
        Your LiveKit Server
        (self-hosted)
                  |
                  |
          AI Voice Agent
                  |
        ------------------
        |                |
       STT            TTS
        |
        |
    LangGraph + LLM
```

You manage:

✅ LiveKit server  
✅ API key/secret  
✅ Agents  
✅ AI pipeline  

You do not pay LiveKit Cloud fees.

---

So the correct statement:

❌ "Self-hosted LiveKit needs no API keys"  
✅ "Self-hosted LiveKit does not need LiveKit Cloud API keys, but it uses your own self-generated LiveKit API key and secret."
